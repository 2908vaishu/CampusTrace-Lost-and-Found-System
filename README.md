# CampusTrace – Lost and Found Management System

CampusTrace is a UI-based Lost and Found Management System designed to help students and faculty report, track, and recover lost items on campus easily. The platform provides a clean, modern, and user-friendly interface for smooth navigation and quick reporting.

## 🔹 Project Overview
CampusTrace acts as a digital campus portal where users can:
- Report lost items
- Search for found items
- Track item recovery
- Connect with fellow students and faculty

The goal is to make the lost-and-found process **simple, fast, and efficient**.

## 🔹 Features
- Modern and responsive UI design  
- Simple navigation and clear layout  
- Easy item reporting system  
- Search and tracking functionality  
- Clean and user-friendly interface  

## 🔹 Technologies Used
- HTML  
- CSS  

## 🔹 Screens / Pages
- Home Page – Introduction & navigation  
- Report Item Page – Submit lost or found item details  
- Item Listing Page – View and search items  

## 🔹 How to Run the Project
1. Download or clone the repository  
2. Open the `index.html` file in any web browser  
3. Explore the interface and features  

## 🔹 Project Objective
To create a **centralized digital platform** for campus communities that helps in quick reporting and recovery of lost belongings, reducing manual effort and saving time.
